# CONTINUATION

After interruption, identify the task from explicit context and inspect existing task records, artifacts, pending questions, approvals, checks, working tree, index and HEAD. Preserve historical journals, run records and user data at their original paths. Separate claimed completion from verified effects; establish approved scope, outstanding work and next action from current evidence.

For each uncertain launch, write, external effect or commit, inspect available host records and resulting artifacts before acting. A missing reply is not evidence that the effect failed. If the effect cannot be established, report the uncertainty and stop that action; do not replay it automatically. Continue independent authorized work only when it does not depend on the uncertain effect.

Use native continuation of an existing session only if the active client actually supports it and the identity is available. Do not transfer a session identity between clients or promise recovery of an old session. Otherwise, after reconciling effects, start a fresh bounded worker with current context and any validated answer. An unanswered question, stale approval or changed artifact grants no authorization. Obtain a fresh decision for changed scope or unresolved material questions. Record the evidence, limitation and next action in existing task records where useful.
