# rnd-grill

## Purpose

Обсуждать неопределенность и согласовывать решения на основе доступных доказательств без записи результатов.

## Ownership

`rnd-grill` ведет обсуждение и читает существующие project specs, glossary, карту и другие относящиеся документы. Правила чтения project specs принадлежат `sync-spec`; долговременные контракты и существенные причины реализованного также принадлежат `sync-spec`.

## Boundaries

Вызов разрешает исследование и разговор, но не запись документов, кода, тестов, прототипов, Git или настроек. По просьбе сохранить результат предложить `to-spec`, не запускать его автоматически.

## Contracts

- Выяснять доступные факты самостоятельно, разделять наблюдения, выводы и допущения, показывать противоречия источников.
- Задавать независимые существенные вопросы с решенными предпосылками вместе, каждый с вариантами, последствиями и рекомендацией; зависимые вопросы ждут ответа. Не навязывать интервью ясному запросу.
- По завершении передавать согласованное и причины, предложения, открытые вопросы и пределы доказательств; отсутствие документов не блокирует обсуждение.
