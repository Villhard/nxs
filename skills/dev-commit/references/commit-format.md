# Коммиты

Выбранный scope определяет изменения для коммита. Осмысленные группы отражают результаты работы, сохраняя посторонние staged и рабочие изменения.

Формат сообщения задают пользовательские и проектные правила, включая `Коммиты` в `## nxs`. При отсутствии своего формата ориентир - короткая строка `<type>(<scope>): <subject>`.

Перед коммитом проверяется предназначенный для него diff: он соответствует выбранной группе и результату проверок. Способ подготовки index зависит от фактического состояния репозитория.

Результат операции - commit IDs и оставшиеся изменения с различением выбранной работы и постороннего остатка. При пустом scope результатом будет отсутствие нового коммита.
