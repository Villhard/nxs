# /dev-commit

По явному вызову закоммить существующие правки в указанном охвате. Без указанного охвата определи атомарные группы только своей разрешенной работы; чужое и неясное не включай. Нечего коммитить - no-op.

Примени [процедуру формата и staging](references/commit-format.md). Не меняй рабочие файлы, не делай push и не расширяй полномочия. Верни созданные commit IDs и оставшиеся staged, unstaged и untracked изменения, отделив чужие; назови препятствия.
