# /dev-commit

Выбери существующие изменения в указанном охвате и сгруппируй их по смыслу, сохраняя чужую работу. Примени [формат коммитов](references/commit-format.md) и проверь предназначенный diff каждого коммита. Верни IDs созданных коммитов и оставшиеся изменения; если коммитить нечего, сообщи об этом.
