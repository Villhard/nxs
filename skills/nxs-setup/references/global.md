# ГЛОБАЛЬНАЯ НАСТРОЙКА

Сначала прочитай основные правила и правила написания. Global настраивает shared instructions поддержанных клиентов, не устанавливает/обновляет/удаляет/запускает скиллы. Только нужное запросу. Частные пути, local facts, secrets, client-specific material не переноси в shared source/repo без одобрения точных содержания/места.

## АУДИТ

1. Проверь shared source `~/.agents/AGENTS.md` и client instructions `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.config/opencode/AGENTS.md`. Разреши symlinks, сгруппируй realpaths. Прочитай текст, запиши source/wiring/conflicts/missing. Не предполагая поддержку непроверенного link.
2. Посчитай `## nxs` в source и предлагаемом merge. Несколько - стоп с путями/строками для ручной сверки. Для каждого правила [шаблона](../assets/global-section.md) эквивалент вне своей секции считай покрытым, конфликты назови, предложи лишь непокрытое. Сохрани пользовательский текст/final newline вне одобренного.
3. Claude Code: wired при import shared source или ссылке на него. Codex/OpenCode: symlink на source. Для отсутствующего пути предложи соответственно import/symlink. Сохрани Claude-only слой. Иной Codex/OpenCode file/link сначала полностью включи в предложенный source merge, затем предлагай замену client path. Реальный файл объединяй один раз, прежние targets сохрани. Приватность/конфликт блокируют безопасный merge - останови эту правку.
4. Если охват требует local tracker/domain guidance, прочитай [tracker](../assets/issue-tracker.md), [метки](../assets/triage-labels.md), [доменные правила](../assets/domain.md) и соответствующее в `~/.agents/docs/`. Только нужные точные diffs к существующему, не полная замена пользовательского текста. Реальные test/lint команды узнавай из проекта, не выдумывай. Tracker необязателен: tickets/исполнение у `dev-exec`, подготовительные/доменные записи у `rnd-grill`. Малому запросу не нужны tracker/spec/journal. Не вводи обязательные logging/map state/координацию и не мигрируй/не чисти старые записи.
5. Установленные skills/provenance сообщай лишь по нужде. Имя, каталог, lock не разрешают замену и не доказывают регистрацию. Сохрани сторонние установки/пользовательские правки. Отдельно запрошенная замена требует точных путей/provenance, сохранения правок, изолированной проверенной замены, реальной регистрации и разрешения. Не хватает доказательств - установку не трогай.

## ПАКЕТ И ПРИМЕНЕНИЕ

Одним пакетом покажи аудит, границы приватности, unified diffs всех файлов, link targets и замен. Получи одобрение всего; пересмотренный пакет покажи заново. Отказ ничего не пишет; актуальное - no-op.

После одобрения сверь source/target с предложением; конкурентное не затирай, непокрытое покажи/согласуй. Запиши точно одобренные source/docs. До links проверь merge, при сбое links не меняй. Примени одобренный wiring, не меняя прежние symlink targets. Проверь файлы по пакету, resolved links, сохранность текста и newline sentinels. Раздельно сообщи правки, конфликты, missing capability и непроверенную регистрацию. Wiring/readiness не доказывают workflow compatibility; source change не разрешает обновить установки/личные настройки.
