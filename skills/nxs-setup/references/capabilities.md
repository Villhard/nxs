# КАРТА ВОЗМОЖНОСТЕЙ

Это маршруты исходников, не доказательство регистрации/поведения клиентов. Setup их не запускает; передача не включает следующий skill.

| Намерение | Владелец |
| --- | --- |
| Обсудить неопределенность и зависимые решения без записи | `rnd-grill` |
| Сохранить согласованную спецификацию задачи и план | `to-spec` |
| Разбить согласованную работу на tickets | `to-tickets` |
| Исследовать сбой и подтвердить причину без исправления | `rnd-debug` |
| Исполнить один готовый ticket проверенными атомарными коммитами | `dev-exec` |
| Независимо проверить работу | `dev-review` |
| Обновить project specs по реализованным контрактам | `sync-spec` |
| Закоммитить существующие правки | `dev-commit` |
| Согласовать и применить настройки | `nxs-setup` |

Для небольшой задачи достаточно одного ticket; вне `dev-exec` обычная работа агента не запрещена. Обсуждение и подготовка не требуют native subagents; `dev-review` требует двух независимых native reviewers. Setup не устанавливает skills и не регистрирует aliases.
