## nxs

- Проектные спецификации: до правки файла перечисли корень и все родительские каталоги, найди точные `SPEC.md`/`.SPEC.md` и прочитай от корня. Меняет их только /sync-spec.

- Ветки: <Обязательно: правило из шага 3 аудита.>
- Тесты: <Необязательно: полный test suite; без найденной команды удали строку.>
- Линтер: <Необязательно: команда; без найденной команды удали строку.>
- Проверка типов: <Необязательно: команда; без найденной команды удали строку.>
- Трекер: <Необязательно: путь к Markdown-инструкции; project setup по умолчанию `.scratch/nxs/issue-tracker.md`.>
- Коммиты: <Необязательно: формат сообщений и ограничения проекта.>

Обязательные проверки - фактически указанные проектом команды. Отсутствующие, запрещенные и недоступные обязательные проверки остаются непроверенными, не успешными.
