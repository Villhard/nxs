## nxs

- Проектные спецификации: до правки файла перечисли корень и все родительские каталоги, найди точные `SPEC.md`/`.SPEC.md` и прочитай от корня. Меняет их только /dev-spec.

- Ветки: <Обязательно: правило из шага 3 аудита.>
- Тесты: <Необязательно: полный test suite; без найденной команды удали строку.>
- Линтер: <Необязательно: команда; без найденной команды удали строку.>
- Проверка типов: <Необязательно: команда; без найденной команды удали строку.>

"Полный набор тестов и линтер" в ticket означает команды выше. Отсутствующие, запрещенные и недоступные обязательные проверки остаются непроверенными, не успешными.
