## Engineering skill defaults

Apply these only when an engineering skill needs them. A project's own `## Agent skills` instructions override these defaults. Read the matching file when needed.

- Issue tracker: Markdown under `.scratch/<feature-slug>/`. Reference: `~/.agents/docs/issue-tracker.md`.
- Triage labels: the role mappings in `~/.agents/docs/triage-labels.md`.
- Domain documentation: `~/.agents/docs/domain.md`.
