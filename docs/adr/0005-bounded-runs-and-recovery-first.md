# Сначала ограниченные запуски и восстановление, затем параллельность

Статус: частично заменено [ADR 0008](0008-native-subagent-coordination.md) в требовании deterministic Python helpers для запуска, журнала и восстановления.

Цель lead - автономно выполнить одобренный feature plan. Сначала реализовать/проверить полный последовательный цикл, затем прерывание/восстановление, потом parallel worktrees/companions. Это уменьшает число совместных сбоев, не урезая цель. Первый успешный цикл убирает ручную передачу/перенос контекста; обычное восстановление не зависит от реконструкции пользователем.

Workers выполняют ограниченные шаги и возвращают `done`, `needs_input`, `blocked` с кратким выводом/ссылками. Это outcomes, не статусы tickets. Lead может продолжить установленную сессию с ответом. Два клиента не должны управлять одним live TUI. Codex описывает schema-constrained final responses и продолжение в [non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode); реальный skill/question workflow еще требует end-to-end опыта.

Ручной nxs сохраняет обычный диалог/понятный ответ; те же смысловые outcomes идут в журнал, ответ пользователя продолжает текущий чат. JSON envelope относится к controlled workers, не каждому сообщению и не статусу всей функции.

Inventory, launch parameters, outcome validation, журнал и worktree preparation - маленькие deterministic helpers. Lead решает деление, смысл findings и следующий шаг. Используй harness/Git, не универсальный workflow engine. Валидная форма не доказывает завершение: до перехода проверь артефакты, приемку, команды, Git.

Один controller на задачу. Сохраняй значимый прогресс, после прерывания сверь файлы, ветки, процессы. Нет ответа команды - не отсутствие эффекта: не повторяй вслепую migration/commit/launch. Сохрани вопрос и достаточный контекст нужного worker.

Проверь последовательный цикл, продолжение вопроса, прерывание после правок, потерянный ответ, восстановление без дублей. Затем parallel worktrees, combined behavior и integration conflicts. Companions после этой базы; OpenCode после Codex.
